# TreatIQ — AI Dental Treatment Planning Tool

Welcome to **TreatIQ**, an AI-powered dental treatment planning tool designed to help dental students and professionals organize, analyze, and communicate patient treatment plans efficiently.

## 📋 About TreatIQ

TreatIQ is an interactive HTML-based application that simplifies the process of creating, organizing, and tracking phased dental treatment plans. It also supports AI-assisted radiographic analysis and patient-friendly treatment communication.

## 🚀 Features

- **AI Radiographic Insights** — Upload X-rays and generate structured clinical findings
- **Treatment Plan Organization** — Organize dental procedures and treatment phases
- **Patient Case Management** — Track patient information and treatment progress
- **Easy to Use** — Simple, intuitive interface accessible from any browser
- **No Installation Required** — Works directly in your web browser

## 📖 How to Use

### Online (Recommended)
Visit the live version of TreatIQ: [TreatIQ Online](https://musadentistry-hue.github.io/Dr-Schneider/)

### Local Use
1. Clone or download this repository
2. Open `dentaflow_artifact (4).html` in your web browser
3. Start planning!

## 👥 For Students

This tool is designed to help you:
- Learn the principles of treatment planning
- Organize complex cases step-by-step
- Practice clinical decision-making
- Prepare for exams and clinical rotations

## 💡 Tips for Success

1. Start by gathering all patient information
2. Upload X-rays and use the AI analysis to auto-populate findings
3. Plan treatment in phases (immediate, stabilisation, rehabilitation, aesthetics)
4. Review and adjust plans as needed before presenting to patients
